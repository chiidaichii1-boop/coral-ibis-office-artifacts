A museum placard for an office object, presented as an ancient artifact —
in a single line of at most 180 characters.

Run `python3 main.py` and it writes the placard line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default).

> Stapler, c. 1984. Brass binding-iron of the Filing Cult; each staple a small vow that two pages shall never part. Donor unknown. The cult persists.
